# 技能：知识库检索（search）

## 目标

在职业生涯知识库里按主题、项目、岗位、时间、标签检索，给出**带路径和来源**的答案；找不到时说清查询范围和缺口。

## 流程

1. 先 `career_index` 读索引，确认模块结构与记录标题。
2. `career_search` 用关键词（可多词空格分隔）；必要时换同义词再搜（如「知识图谱 / KG / GraphRAG」）。
3. 对候选记录 `career_read` 读全文，不要只看片段下结论。
4. 回答结构：
   - 直接结论（1–3 句）
   - 证据：每条事实后标来源 `[[记录标题]]` 或路径
   - 相关记录：2–5 个可选延伸
   - 缺口：没有查到什么、可能在哪、建议下一步
5. 多段经历匹配时列出候选，不要武断合并。
6. 不编造记录内容；模型记忆不等于知识库记录。

## 输出

```
结论：...

依据：
- ...（来源：04-项目与成果沉淀/项目档案/xxx.md）
- ...（来源：02-求职与实习/面试复盘/xxx.md）

关联：[[...]]、[[...]]

未找到：...；建议：...
```

## 正反例

**好**：用户问「我面试里讲过的知识图谱准确率是多少」，检索到面试复盘与项目档案都写了 50%→90%，指出两处一致，并说明口径来自自建测试集。
**不好**：回答「大概 90% 多吧」，不给路径，或把项目档案里的 50%→90% 说成「95%」。
