# 分类正反例

> 判断标准：先看「主要用途」和「稳定对象」，不要只按关键词。每条事实只有一个主档，其他位置用链接引用。

| 内容 | 正确模块 | 反例 | 理由 |
| --- | --- | --- | --- |
| 「费曼学习法」步骤笔记 | 03 学习笔记 | 04 项目档案 | 通用方法，不是亲历项目 |
| 某岗位 JD 与投递判断 | 02 岗位库 | 03 学习笔记 | 对象是具体求职流程 |
| 「我在实习中搭了进度看板」 | 04 实习复盘 | 03 能力建设 | 已发生的亲历事实 |
| 「我最擅长结构化拆解」 | 05 个人画像 | 03 技能树 | 稳定的自我认知，需证据支撑 |
| 「2026 具身智能融资趋势」 | 06 行业观察 | 01 职业规划 | 外部行业信息 |
| 「未来 5 年想转 AI 产品」 | 01 职业规划 | 05 个人画像 | 未来目标，不是稳定背景 |
| 面经（某公司某轮） | 02 面试复盘/岗位库 | 03 面经笔记 | 绑定具体岗位与流程 |
| 面试通用题库 | 03 方法论 或 02 面试准备 | 06 行业洞察 | 看用途：通用方法 vs 该岗准备 |
| 简历版本 | 02 简历版本 | 05 个人背景 | 按岗位与日期独立版本 |
| 项目成果数字 | 04 项目主档 | 02 简历 | 简历只引用，不另存一份事实 |

## 判定顺序

1. 这条记录服务的是「未来目标」「具体求职」「正在学的能力」「已发生的项目」「稳定背景」还是「外部行业」？
2. 有没有已有的同一对象主记录？有就更新/补充，不新建。
3. 主分类清楚但子类不清楚：用主分类 + 注明子类待定。
4. 主分类也不清楚：列 2–3 个候选与理由，询问用户，不新建「其他」目录。

## 常见错误

- 按关键词分类：「带『学习』两个字就放 03」。
- 同一事实在 02 和 04 各维护一份，数字不一致。
- 把他人经验放进 04，或把行业数据放进 01。
- 新建「待分类」「其他」目录逃避判断。
